## 1. VEREDICTO ESTRATÉGICO

**Tier 1 Estándar. NSM: Spotify Followers ganados D-30 a D+30. Postura: CONSTRUCCIÓN DE BASE.**

Tres decisiones estratégicas:
1. **Priorizar conversión sobre alcance.** El artista ya tiene discovery excelente (86.7% IG, 82.4% TT). El gap está en el cierre del funnel — bio link, CTA de follow, pre-save.
2. **Hacer que la música viaje sin el artista.** Tráfico por sonido TT 0.6% = la música no viraliza como sonido. Snippet testing + UGC son la prioridad para que TUCUTÚ exista independientemente del perfil.
3. **Aprovechar la ventana de momentum.** ML en ATH, 17/18 países crecen. El lanzamiento debe capitalizar AHORA antes de que el momentum orgánico se enfríe.

## 5. MAPA DE LOOPS CROSS-PALANCA

### Loop 1: UGC → Sonido → Spotify (CRÍTICO)
```
P4 (UGC oleadas) → Sonido TUCUTÚ circula en TT → Usuarios buscan en Spotify → Streams suben → Algoritmo Spotify empuja → Más listeners → Más followers
```
**Punto de ruptura:** Si los snippets del testing P2 no identifican un hook viral, las oleadas UGC no despegan. **Mitigación:** Testear 5+ snippets diferentes, decidir en D-7 cuál va.

### Loop 2: Pre-save → D0 Streams → Editorial (ALTO)
```
P5 pauta pre-save → Pre-saves acumulados → D0 señal de demanda → Algoritmo Spotify valida → Posible inclusión Release Radar/DW → Más streams
```
**Punto de ruptura:** Si el bio link sigue roto (0.96%), la pauta pre-save no convierte. **Mitigación:** Landing page lista D-15 (HOY).

### Loop 3: Contenido artista → Discovery → Follow → Community → Showcase
```
P1 contenido LIBRE+PROD → Discovery IG/TT (86%+82%) → Visita perfil → Follow → DMs P2 → Invitación showcase P6 → Contenido showcase → Más discovery
```
**Punto de ruptura:** Si el artista no cumple cadencia LIBRE (stories, Lives). **Mitigación:** Calendario día por día del Agente 6 + check-ins semanales.

### Loop 4: Prensa → Credibilidad → Editorial Spotify
```
P3 menciones en medios → Artista tiene press kit → Pitch editorial reforzado → Mayor probabilidad de playlist editorial → UCT-04 activado
```
**Punto de ruptura:** Si ningún medio responde al pitch (T1 sin historial). **Mitigación:** 2 medios extra en pipeline + post propio G*S como respaldo.
