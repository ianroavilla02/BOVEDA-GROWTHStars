## 1. Catálogo de Productos

G*S opera 3 productos independientes bajo el servicio **Lanzamientos Algorítmicos**:

### 1.1 CREATOR! — Auditoría Algorítmica

| Campo | Valor |
|---|---|
| **Precio** | US$ 880 / 3.55M COP |
| **Naturaleza** | One-shot (pago único) |
| **Duración** | Entregable único, ~2-3 semanas |
| **Audiencia** | Artistas con presupuesto limitado, primer contacto |

**Propuesta de valor:**
Auditoría completa basada en análisis de algoritmos de redes sociales.
Roadmap estratégico que cuenta con Estrategia para el Artista, Estrategia
para los Fans, y Activaciones (Triggers Algorítmicos).

**Entregable:** Documento estratégico con plan de acción.

**NO incluye:** Ejecución del plan, costos de variables ni extras.

---

### 1.2 ARTIST! — Lanzamiento 360°

| Campo | Valor |
|---|---|
| **Precio** | US$ 2,500 / 9.36M COP |
| **Naturaleza** | One-shot (pago 50/50) |
| **Duración** | 1 lanzamiento ejecutado (~30-60 días) |
| **Audiencia** | Artistas con scope de lanzamiento concreto |

**Propuesta de valor:**
Servicio 360°. Audita, ejecuta y garantiza ROI para 1 lanzamiento
algorítmico. Incluye toda la metodología CREATOR! más ejecución completa.

**Estructura de pagos:**
- 50% pre-release: US$ 1,250 (4.68M COP)
- 50% release: US$ 1,250 (4.68M COP)

**NO incluye:** EXTRAS opcionales ni VARIABLES (UGC/prensa/pauta).

---

### 1.3 STAR! — Programa ERA (3 meses)

| Campo | Valor |
|---|---|
| **Precio total** | US$ 6,750 / 25.5M COP |
| **Precio mensual** | US$ 2,250 / 8.5M COP |
| **Naturaleza** | Suscripción 3 meses con compromiso contractual |
| **Audiencia** | Artistas que requieren incubación algorítmica + hard release |

**Propuesta de valor:**
Programa de 3 lanzamientos consecutivos bajo branding unificado de "ERA":
- **Mes 1:** Single #1 (warmup del algoritmo)
- **Mes 2:** Single #2 (intensificación del algoritmo)
- **Mes 3:** HARD RELEASE (peak del algoritmo aprovechando momentum)

Durante 3 meses, trabajamos el algoritmo para maximizar rendimiento del
hard release final.

**Estructura de pagos:**
- Mes 1: 50% pre + 50% release del lanzamiento 1
- Mes 2: 50% pre + 50% release del lanzamiento 2
- Mes 3: 50% pre + 50% release del hard release

**Compromiso contractual:**
Cliente firma contrato a 3 meses. Cláusula de salida temprana permite
abandonar sin penalización adicional, pero pierde lo invertido hasta
ese momento.

## 2. Reglas de Upgrade entre Productos

### 2.1 CREATOR! → ARTIST!

**Descuento aplicable:**
- Si el cliente upgrade dentro de 30 días desde compra de CREATOR!:
  Se acredita el valor total de CREATOR! (US$ 880) al precio de ARTIST!.
  Cliente paga: US$ 2,500 - US$ 880 = US$ 1,620.

**Fuera de la ventana de 30 días:**
- Cliente paga precio ARTIST! completo (US$ 2,500).
- Razón: auditoría debe re-ejecutarse (data desactualizada).

### 2.2 ARTIST! → STAR!

**Modelo de continuidad:**
- Lanzamiento 1: precio ARTIST! (US$ 2,500) — ya pagado.
- Lanzamientos 2-3: precio STAR! mensual (US$ 2,250 × 2 = US$ 4,500).
- **Total contrato:** US$ 7,000.

**Nota intencional:**
ARTIST!→STAR! sale US$ 250 más caro que STAR! upfront (US$ 6,750).
Esta diferencia es deliberada para incentivar compromiso STAR! desde
el inicio. No es error de pricing.

### 2.3 Reglas generales

- Los 3 productos son **mutuamente excluyentes en simultáneo**.
- Durante STAR!, el cliente NO puede tener otros productos G*S
  paralelos (otro ARTIST! para single random fuera del programa ERA).
- EXTRAS sí se pueden sumar a cualquier producto activo.

## 6. Lógica de Propuesta del Cotizador

### 6.1 Estructura de 3 Escenarios

El cotizador presenta **3 escenarios** para que el cliente elija:

| Escenario | Composición | Audiencia |
|---|---|---|
| **A — Básico** | Solo paquete principal (sin EXTRAS) | Cliente con presupuesto mínimo |
| **B — Recomendado** | Paquete + EXTRAS críticos sugeridos | Cliente con presupuesto medio |
| **C — Premium** | Paquete + todos los EXTRAS aplicables | Cliente con presupuesto alto |

### 6.2 Composición de cada escenario

Cada escenario incluye:
1. **Paquete base** (CREATOR!/ARTIST!/STAR! según recomendación).
2. **EXTRAS** (variable según escenario).
3. **VARIABLES estimadas** con disclaimer.
4. **Total estimado** USD + COP.
5. **Estructura de pagos** según producto.

### 6.3 Selección del paquete base

El cotizador recomienda paquete base según:
- **Tier del artista** (definido en auditoría).
- **Scope del Strategy Brief** (cantidad de activaciones propuestas).
- **Presupuesto declarado** (si el cliente lo expresó).

Regla general:
- Tier 1 Emergente + scope básico → CREATOR! o ARTIST!
- Tier 2-3 Establecido + scope amplio → ARTIST! o STAR!
- Tier que requiere incubación pre-hard release → STAR!

## 8. Política de Actualización

Este documento es la **fuente de verdad operativa** del cotizador.

**Cuándo actualizarlo:**
- Cambio de precios de productos.
- Definición de precios de EXTRAS pendientes (Branding por tier).
- Ajuste de rangos de VARIABLES.
- Cambio de tasa USD/COP de referencia.
- Política de descuentos nueva.

**Cómo actualizarlo:**
1. Editar este .md en `01_METODOLOGIA/`.
2. Incrementar la versión (1.0 → 1.1 → 2.0).
3. Commit con mensaje: `chore: update MODELO-ECONOMICO-GS to vX.Y`.
4. El cotizador automáticamente lee la versión actual.

**Sin tocar código del agente.**
